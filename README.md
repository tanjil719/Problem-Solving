## 🗂 Project Structure
```
Problem-Solving/
├── src/                # All solutions, one class per problem
│   ├── Pro<Number>.java
│   └── ...
└── README.md
```

Each solution class is self-contained and named after its LeetCode problem number (e.g. `Pro1.java` solves [Two Sum](https://leetcode.com/problems/two-sum/)), making it easy to jump straight to a specific problem.

## 🚀 Getting Started

**Prerequisites:** [JDK 8+](https://www.oracle.com/java/technologies/downloads/) and an IDE such as IntelliJ IDEA (this project includes `.idea` config).

Compile and run any single solution directly:

```bash
javac src/Pro1.java -d out
java -cp out Pro1
```

Or open the project in IntelliJ IDEA and run individual classes from the editor.
